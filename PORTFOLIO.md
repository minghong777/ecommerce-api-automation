## Description (maximum 600 characters)

Built a Python e-commerce operations demo with a public product API, normalized data, a Streamlit sales dashboard, and filtered CSV/JSON/Excel reports. A standalone CLI syncs summary metrics, orders, and product sales to Google Sheets. Two real syncs and full API read-back verified 240 unique orders with no duplicates on 2026-10-23. The public dashboard has no Sheets write action; scheduling templates are provided but inactive. Independent portfolio project; all customers, orders, and revenue are synthetic.
