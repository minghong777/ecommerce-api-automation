## Title

E-commerce API & Operations Automation

## Role

Python Developer | API Integration & Automation

## Project description (under 600 characters)

Built a Python e-commerce operations demo that integrates a public product API, normalizes data, and generates deterministic synthetic orders. A Streamlit dashboard provides consistent filters, sales analytics, and CSV/JSON/Excel exports. An independent CLI synchronizes summary, orders, and product sales to Google Sheets using protected service-account credentials. Two real syncs were verified by API read-back with 240 unique orders and no duplicates. Independent portfolio project; all customers, orders, and revenue are fictional.
